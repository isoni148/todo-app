# Soni Todo App

A simple Todo App built using HTML, CSS, and JavaScript.

## Features

- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Dark Mode
- Task Counter
- Local Storage Support
- Search Tasks

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project.
2. Open the project folder.
3. Open index.html in your browser.
